Light Master Pro includes two main types of assets: digitally simulated light patterns, such as caustics and rays, and assets created from real-world light references, including photographed or observed lighting behavior. AI-assisted tools were used only as part of the production workflow for some assets. For certain real-world light references, AI helped isolate the light pattern from the original background more accurately and with minimal quality loss. You can view examples using the buttons below. AI upscaling tools were also used for selected assets to increase texture resolution, and in a few cases AI-assisted cleanup was used to remove digital artifacts more cleanly, as shown in the “Digital Artifact Removal” example. However, the library is not a set of raw AI-generated images. No assets were added as purely AI-generated light patterns without a real-world photo reference, observed light behavior, or a controlled digital simulation as the source. Every final asset was manually reviewed, post-processed, cleaned, adjusted, categorized, and optimized for use in Blender and 3D production. Even when AI-assisted tools were used, the final result was refined by hand to make sure the textures are practical, clean, and visually useful for real render workflows.
